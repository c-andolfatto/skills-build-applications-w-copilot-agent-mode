# OctoFit Tracker frontend

Run the Vite presentation tier with:

```bash
npm run dev --prefix octofit-tracker/frontend
```

Define `VITE_CODESPACE_NAME` in `octofit-tracker/frontend/.env.local` when you want the app to call the Codespaces API URL. When it is unset, the frontend safely falls back to `http://localhost:8000`.
